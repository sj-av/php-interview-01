# Подготовка PHP middle+ — Laravel + PostgreSQL

Цель: уверенно решать backend-задачи, объяснять решения и проходить техническое собеседование. Целевых вакансий пока нет. Дата создания: 2026-11-11.

## Начало

1. Открой эту директорию как проект в Codex.
2. Попроси: «Прочитай AGENTS.md и resume.md. Начни диагностику, задавай по одному вопросу».
3. После диагностики скорректируй приоритеты в plan.md.

Необязательно читать вопросы диагностики заранее: их можно оставить интервьюеру.

## Файлы

- `plan.md` — программа и критерии освоения.
- `progress.md` — оценки по фактически проверенным навыкам.
- `mistakes.md` — ошибки и очередь повторения.
- `resume.md` — компактное состояние для нового чата.
- `diagnostic.md` — начальная диагностика.
- `exercises/README.md` — практические задачи и критерии проверки.
- `sessions/TEMPLATE.md` — шаблон результата занятия.
- `prompts.md` — команды для разных форматов занятий.
- `sources.md` — официальные справочники.

## Режим

Ориентир занятия: 5–10 минут повторения, 20–30 минут вопросов или кода, 10 минут разбора и сохранения результата. Это рекомендация, не обязательный график. Срок подготовки и доступное время пока неизвестны.

Новая беседа начинается с resume.md, progress.md и нужного раздела plan.md. Не нужно загружать весь архив занятий. Перед окончанием занятия попроси сохранить контрольную точку; если лимит оборвал работу, следующий чат продолжает с последней сохранённой точки.

Субагенты не обходят лимиты использования. Подключай их по явному запросу для независимого ревью или отдельного интервью. Основной агент объединяет результаты и обновляет состояние.

Рабочее приложение, зависимости и Docker здесь пока не устанавливались. Версии PHP, Laravel и PostgreSQL нужно зафиксировать перед первым упражнением по имеющемуся окружению; не считать какую-либо версию установленной по умолчанию.
